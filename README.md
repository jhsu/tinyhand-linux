# TinyHand Linux

A Linux/Wayland presentation pointer inspired by [TinyHand](https://github.com/nilbuild/tinyhand): a tiny hand on a stick that points at things on your screen.

It uses GTK4 + `gtk4-layer-shell` to draw a transparent overlay above everything, and PipeWire to play a tap sound.

## Use

While the pointer is on:

| | |
|---|---|
| Move the mouse | The hand follows, held on a rod from below the screen |
| Click (any button) | Tap: a press animation and sound. Nothing underneath gets clicked |
| Hold and drag | Draw on the screen. Strokes fade after 3 seconds |

The keyboard is never captured, so arrow keys and other shortcuts keep going to your presentation.

The pointer is controlled by commands, which are sent to the running instance (starting it if needed):

```bash
tinyhand-linux            # turn the pointer on
tinyhand-linux --toggle   # turn it on or off
tinyhand-linux --off      # turn it off and clear the drawing
tinyhand-linux --clear    # clear the drawing
tinyhand-linux --quit     # stop the running instance
```

Wayland doesn't let an app watch for keys in the background, so bind the commands in your compositor. For niri, in `~/.config/niri/config.kdl`:

```kdl
binds {
    Ctrl+Alt+H { spawn "tinyhand-linux" "--toggle"; }
    Ctrl+Alt+X { spawn "tinyhand-linux" "--clear"; }
}
```

## Requirements

- Wayland compositor with layer-shell support (tested against niri)
- GTK 4.14+ and gtk4-layer-shell
- `pw-play` for the tap sound
- Rust toolchain

On Arch-like systems, the runtime dependencies are `gtk4`, `gtk4-layer-shell`, and PipeWire.

## Build and run

```bash
cargo build --release
./target/release/tinyhand-linux
```

Or install to `~/.local/bin` with `./install.sh`.

The application loads assets from the project directory, then `~/.local/share/tinyhand-linux`. To use another asset directory:

```bash
TINYHAND_ASSETS=/path/to/assets tinyhand-linux
```

## Scope and limitations

This is a Linux implementation of TinyHand's core pointer, not a full port. It has one hand style, no toolbar or settings, and no way to click through to the app underneath while the pointer is on (the original's hold-⌥ to click). Turn the pointer off to interact normally.

The original TinyHand repository is MIT licensed; this implementation is an independent Linux implementation and is also MIT licensed. `assets/hand_pastel.png` comes from TinyHand. The tap sound, `assets/tap_plastic.wav`, is generated by `scripts/make-tap.py` (needs numpy).
